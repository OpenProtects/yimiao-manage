# 支付渠道配置教程

## 一、支付宝配置

### 1. 获取配置信息

登录支付宝开放平台: https://open.alipay.com/

1. 创建应用，获取 **AppId**
2. 获取 **应用私钥** (应用私钥)
3. 获取 **支付宝公钥** (支付宝公钥)

4. 配置应用公钥 (将你的公钥上传到支付宝)

### 2. 配置参数说明

| 参数 | 说明 |
|------|------|
| API地址 | `https://openapi.alipay.com/gateway.do` (正式环境) 或 `https://openapi.alipaydev.com/gateway.do` (沙箱环境) |
| AppId | 支付宝应用的唯一标识 |
| AppSecret | 应用密钥，用于签名 |
| 商户ID | 通常与AppId相同或单独的商户号 |
| 商户私钥 | 你生成的RSA私钥 |
| 平台公钥 | 支付宝的公钥，用于验证签名 |
| 回调地址 | 支付成功后的异步通知地址，如 `https://your-domain.com/api/payment/notify/alipay` |
| 返回地址 | 支付完成后跳转的前端页面，如 `https://your-domain.com/pay/result` |

### 3. 签名说明

支付宝使用RSA2签名算法:
- 使用商户私钥对请求签名
- 使用支付宝公钥验证响应签名

### 4. 测试模式

沙箱环境用于开发测试:
- 沙箱AppId: 在沙箱页面获取
- 沙箱买家账号: 在沙箱页面获取测试买家账号
- 沙箱卖家账号: 你的沙箱商户账号

## 二、微信支付配置

### 1. 获取配置信息

登录微信支付商户平台: https://pay.weixin.qq.com/

1. 获取 **AppID** (公众号/小程序/开放平台应用ID)
2. 获取 **商户号 (mch_id)**
3. 设置 **API密钥** (API安全设置)
4. 下载 **商户证书** (apiclient_cert.p12)
5. 获取 **商户证书序列号** (apiclient_key)

### 2. 配置参数说明

| 参数 | 说明 |
|------|------|
| API地址 | `https://api.mch.weixin.qq.com` (正式环境) 或 `https://api.mch.weixin.qq.com/sandboxnew` (沙箱环境) |
| AppId | 微信公众号/小程序的AppID |
| AppSecret | AppSecret (可选) |
| 商户ID | 微信支付商户号 |
| 商户私钥 | 商户证书中的私钥内容 |
| 平台公钥 | 微信支付平台证书内容 |
| 回调地址 | 支付成功后的异步通知地址 |
| 返回地址 | 支付完成后跳转的前端页面 |

### 3. 签名说明

微信支付使用MD5或RSA签名:
- MD5签名: 使用API密钥
- RSA签名: 使用商户私钥签名

## 三、易支付配置

### 1. 获取配置信息

易支付是第三方聚合支付平台，请联系您的易支付服务商获取:
- 商户ID
- 商户密钥

### 2. 配置参数说明

| 参数 | 说明 |
|------|------|
| API地址 | 易支付网关地址，如 `https://pay.example.com/` |
| 商户ID | 易支付分配的商户ID |
| AppSecret | 易支付分配的密钥 |
| 回调地址 | 支付成功后的异步通知地址 |
| 返回地址 | 支付完成后跳转的前端页面 |

### 3. 常见易支付平台

- 彩虹易支付
- 马支付
- 其他第三方聚合支付

## 四、本地开发测试

### 1. 使用Mock模式

在开发环境中，可以使用Mock模式模拟支付:

```java
// 在application.yml中配置
payment:
  mock: true
```

### 2. 测试流程

1. 创建测试订单
2. 调用支付接口
3. 模拟支付成功回调
4. 验证订单状态变更

### 3. 测试接口

系统提供了聚合支付测试接口，可用于本地测试:

```
POST /payment/test/create
{
  "amount": 0.01,
  "channelCode": "alipay",
  "subject": "测试支付"
}
```

## 五、安全注意事项

1. **私钥保护**: 商户私钥必须严格保密，不要提交到代码仓库
2. **HTTPS**: 生产环境必须使用HTTPS
3. **签名验证**: 必须验证回调签名，防止伪造
4. **金额校验**: 回调时验证金额是否一致
5. **幂等处理**: 同一订单的多次回调应幂等处理

## 六、常见问题

### 1. 签名错误
- 检查私钥格式 (是否包含BEGIN/END标记)
- 检查字符编码 (UTF-8)
- 检查是否有多余空格或换行

### 2. 回调未收到
- 检查服务器是否能被外网访问
- 检查防火墙设置
- 检查回调URL是否正确

### 3. 支付超时
- 检查网络连接
- 检查支付渠道服务状态
- 检查订单超时设置
